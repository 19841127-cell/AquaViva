jQuery

jQuery es una biblioteca de JavaScript creada para facilitar tareas comunes como manipular elementos HTML, manejar eventos y crear animaciones.

¿Por qué nació jQuery?

jQuery surgió para simplificar el desarrollo web y facilitar la compatibilidad entre diferentes navegadores.

Sintaxis básica


$("#boton").click(function() {
    alert("Hola desde jQuery");
});

Ventajas y desventajas

Ventajas Desventajas
Sintaxis sencilla. Puede ser innecesario en proyectos modernos.
Facilita algunas animaciones. Agrega una dependencia externa.
Fue muy útil para compatibilidad entre navegadores. JavaScript moderno ofrece muchas funciones similares.

Ejemplo de animación

jQuery permite utilizar efectos como fadeIn() y slideToggle(). 


$("#informacion").slideToggle();
¡Este contenido puede aparecer y desaparecer con una animación!
