JSON

JSON significa JavaScript Object Notation. Es un formato ligero utilizado para almacenar e intercambiar información.

¿Cómo está estructurado?

JSON utiliza pares de clave y valor. También permite trabajar con objetos y arreglos. 


{
    "producto": "AquaViva",
    "precio": 15.99,
    "colores": [
        "azul",
        "verde",
        "blanco"
    ],
    "disponible": true
}

Objeto JavaScript vs JSON

Objeto JavaScript Cadena JSON
{ nombre: "AquaViva" } { "nombre": "AquaViva" }
Puede contener funciones. Solo contiene datos.

JSON y las aplicaciones web

Las aplicaciones web pueden utilizar JSON para enviar y recibir información entre el navegador y un servidor. También es muy utilizado cuando una aplicación se comunica con una API.

Ejemplo


const producto = {
    nombre: "AquaViva",
    precio: 15.99
};

const datos = JSON.stringify(producto);
