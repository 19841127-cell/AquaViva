Web Hosting y Dominios

Para que una página web pueda ser visitada desde Internet necesita estar alojada en un servidor y tener una dirección que permita encontrarla.

¿Qué es Web Hosting?

El Web Hosting es un servicio que proporciona espacio y recursos en un servidor para almacenar los archivos de un sitio web y permitir que los usuarios accedan a ellos mediante Internet.

Tipos de Hosting

Hosting compartido

Varios sitios web utilizan los recursos de un mismo servidor.

VPS

Un servidor físico se divide en servidores virtuales con recursos asignados.

Hosting en la nube

Utiliza recursos distribuidos entre diferentes servidores.

Vercel

Vercel es una plataforma que permite desplegar aplicaciones y sitios web. Para un sitio estático, los archivos del proyecto pueden publicarse y quedar disponibles mediante una dirección web.

¿Qué es un dominio?

Un dominio es el nombre que las personas utilizan para acceder a un sitio web, por ejemplo:

www.aquaviva.com

TLD

TLD significa Top-Level Domain. Es la parte final de un dominio.

  • .com → comercial
  • .org → organizaciones
  • .net → originalmente relacionado con redes

Subdominio

Un subdominio es una sección adicional ubicada antes del dominio principal.

Ejemplo: blog.aquaviva.com

Propagación DNS

🌐 Usuario
↓
🔎 DNS
↓
🖥️ Servidor
↓
🌐 Sitio Web

Cuando se configura un dominio, los cambios de DNS necesitan tiempo para actualizarse y ser reconocidos por diferentes servidores de Internet. Este proceso se conoce como propagación DNS.
