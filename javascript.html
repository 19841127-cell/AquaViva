JavaScript

JavaScript es un lenguaje de programación utilizado principalmente para agregar interactividad y comportamiento a las páginas web.

HTML, CSS y JavaScript

Tecnología Función
HTML Define la estructura y el contenido.
CSS Define el diseño, colores y apariencia.
JavaScript Agrega comportamiento e interactividad.

Conceptos básicos

Variables

Permiten almacenar información que puede utilizar un programa.

Funciones

Son bloques de código diseñados para realizar una tarea específica.

Eventos

Son acciones que ocurren en la página, como hacer clic sobre un botón.

Ejemplo práctico


const boton = document.querySelector("#boton");

boton.addEventListener("click", function() {
    alert("¡Bienvenido a AquaViva!");
});
